# Gallery Walk

A strange, walkable browser museum for images, audio, video, PDFs, and other files. Visitors can enter the archive, move between podiums with the arrow keys or controls, and search by name or file type.

## Open the site

Open `index.html` in a modern browser. No install, build, or server is required.

Files are kept in this browser's IndexedDB storage and stay on this device. Clearing browser site data removes the collection. Browser storage has a size limit, so very large files may not fit. This local-only version does not share exhibits with other people's devices; shared public viewing would need hosted file storage, which this project intentionally does not use.

## Use

- The gallery fills the webpage when entered; it does not use browser fullscreen.

- Choose **Add to the room** to add one or more files while in curator mode.
- Rename or remove the selected podium while in curator mode.
- Use the left and right arrow keys or the on-screen arrows to walk between podiums.
- Search for a podium by title or file type, then choose a result to jump there.
- Ask Iris, the animated eye, for a podium number, title, or file type. Tell Iris **take us back** to return to the foyer.
- Images, audio, video, and PDFs preview in the room. Other file types appear as labeled archive objects.
